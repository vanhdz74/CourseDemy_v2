# 🎓 CourseDemy – Nền tảng bán khóa học lập trình

![CourseDemy Banner](https://dummyimage.com/1200x300/4f46e5/ffffff\&text=CourseDemy+-+Learn+Programming+Online)

> **CourseDemy** là một nền tảng web bán khóa học lập trình trực tuyến, giúp học viên dễ dàng tiếp cận kiến thức từ cơ bản đến nâng cao, đồng thời hỗ trợ giảng viên quản lý và phân phối khóa học hiệu quả.

---

## 🚀 Tính năng chính

### 👨‍🎓 Dành cho Học viên

  * Đăng ký / đăng nhập tài khoản
  * Duyệt & tìm kiếm khóa học theo danh mục
  * Mua khóa học và học trực tuyến
  * Xem tiến độ học tập
  * Quản lý hồ sơ cá nhân

### 👨‍🏫 Dành cho Giảng viên

  * Tạo và quản lý khóa học
  * Upload video bài giảng
  * Quản lý học viên tham gia khóa học

### 🛠️ Dành cho Admin

  * Quản lý người dùng (CRUD)
  * Quản lý khóa học & danh mục
  * Phân quyền hệ thống
  * Theo dõi thống kê

---

## 🧩 Công nghệ sử dụng

### Front-end

  * ⚛️ **Next.js** (React)
  * 🎨 **Tailwind CSS**
  * 🔐 **NextAuth** (Authentication)
  * 🌐 Fetch API / Axios

### Back-end

* 🟢 Java Spring Boot (áp dụng kiến trúc 3 lớp)
* 🗄️ Database: MySQL
* 🔑 JWT (Access Token & Refresh Token)

---

## ⚙️ Cài đặt & Chạy dự án

### 1️⃣ Clone repository

```bash
git clone https://github.com/vanhdz74/CourseDemy2.git
cd CourseDemy2
```

### 2️⃣ Cài đặt dependencies

```bash
npm install
# hoặc
yarn install
```

### 3️⃣ Chạy môi trường development

```bash
npm run dev
```

Truy cập: **[http://localhost:3000](http://localhost:3000)**

---

## 🔐 Authentication Flow (Tóm tắt)

* Đăng nhập bằng Credentials
* Server trả về **Access Token + Refresh Token**
* Access Token dùng cho API
* Refresh Token tự động làm mới khi hết hạn
